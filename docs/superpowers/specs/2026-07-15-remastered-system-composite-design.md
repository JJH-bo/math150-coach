# 重制星系最终合成设计

## 验收目标

在同一个全屏画面内组合已经分别通过的四项视觉资产：冷暗深空星空、相对论 Boss 黑洞、四颗活体恒星、五条等离子场连线。此次不重画单体，只解决合成顺序、透明关系、曝光平衡和构图。

## 画面结构

1. 最底层使用 `cosmos-lab` 的 `abyss` 视角，提供低亮、冷色、真实星表远场。
2. 中间层保留 `boss-lab` 原始相对论渲染；嵌入模式额外输出事件视界遮罩和吸积盘发光透明度，再由主页面透明画布合成，避免 iframe 底色污染星空。
3. 最上层保留 `galaxy-lab` 的四颗重制恒星与五条重制场连线，继续使用 HDR、ACES 和 bloom。
4. 四颗恒星位于画面左侧并互相形成一个核心模块；汇入线指向右侧 Boss，但不让四颗星围绕 Boss 排列。

## 视觉约束

- Boss 必须持续占据右侧主要画幅，尺寸和光学细节不低于已通过版本。
- 星空不得盖住事件视界，不得把吸积盘洗成平面贴图。
- 星空亮度必须低于恒星、连线和 Boss；中心及右侧保留足够黑场。
- 组合页隐藏子实验室 HUD，画面只保留组合页最小验收标签。
- 本轮只进行真实浏览器截图验收，不执行项目测试套件。

## 技术选择

采用三个独立 WebGL2 渲染器和主页面透明合成层。星空 iframe 作为不透明底层并由主页面驱动；Boss iframe 只作为隐藏的物理渲染源，主页面在同一帧把其带透明遮罩的输出复制到 `boss-composite-layer`；系统 canvas 使用 premultiplied alpha 覆盖在最上层。这样既直接复用已经验收的渲染器，也避开浏览器对被遮挡 iframe 的动画节流和不透明底色限制。
