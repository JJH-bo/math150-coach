# 单系重制版视觉设计

## 目标与边界

本轮只制作一个独立视觉样板：四颗普通学习恒星、一个已经通过验收的相对论 Boss 黑洞，以及全新连线系统。画面用于判断“一个核心知识模块是否真正像一个星系区域”，不接入正式知识图谱，不修改课程数据、交互逻辑或 Boss 本体。

四颗普通节点继续使用已经通过单体材质阶段的活体恒星语言；它们不是岩石行星，也不允许退化成带 PBR 高光的球体。Boss 直接复用现有 `boss-lab` 的 Bruneton 光束追踪结果，不重新近似绘制黑洞。

## 构图与拓扑

- 画面只显示四颗学习恒星和一个 Boss，不制造装饰性伪节点。
- 四颗恒星集中在画面左侧，形成一个不对称菱形知识区，而不是排成直线或平均环绕 Boss。
- 拓扑固定为分流后汇合：`入口 -> 上支`、`入口 -> 下支`、`上支 -> 汇合`、`下支 -> 汇合`、`汇合 -> Boss`。
- 前四条线在恒星区内部围出明确面积；只有最后一条主干离开这个局部系统并进入 Boss。
- Boss 位于画面右侧，事件视界与吸积盘占据约一半有效画幅，并允许右边缘自然裁切。四颗恒星全部明显小于 Boss。

## 技术路线判断

拒绝普通 `TubeGeometry`、发光样条管道和大量粒子串。它们的截面、塑料高光或均匀粒子间距会让连线再次成为独立物体，与宇宙背景和节点材质脱节。

采用独立 WebGL2 HDR 合成层：

1. 底层直接嵌入已通过的 `boss-lab`，保持原有相对论光束追踪、吸积盘、光子环和事件视界画质。
2. 上层单次全屏着色器同时绘制四颗隐式体积恒星、五条能量路径和局部空间尘埃。
3. 上层使用浮点 HDR 目标、分级 Bloom 与 ACES 风格色调映射，最终以预乘 Alpha 合成到 Boss 画面。

这种分层保证本轮不会为了组合场景而降低 Boss 的技术等级，同时允许连线使用专门的连续场渲染，而不是几何管道。

## 连线视觉系统

每条连接不是一根线，而是三个共同运动的场：

### 引力流带

以三次贝塞尔路径为骨架，在路径两侧生成宽而低亮度的体积密度。宽度缓慢收缩、扩张并被低频噪声撕开，形成空间被拉伸后的暗色流带。它负责让四颗恒星属于同一个局部区域，但不能遮住恒星材质。

### 等离子纤维

每条流带内部包含多股不等宽、不同相位的细纤维。纤维由连续噪声扭曲，存在断续、交叉和局部亮结，不出现统一圆管边缘。内部路径使用金白与暗琥珀，终端主干逐渐转为红橙色，与 Boss 吸积盘建立色彩连续性。

### 能量脉冲

少量高亮脉冲沿纤维成组传播。脉冲长度、速度和间距均不一致，经过分流点时一分为二，经过汇合点后重新聚集。脉冲只强化方向，不把整条路径变成跑马灯。

## Boss 附近的连接行为

终端主干不会径直插入黑洞中心。接近 Boss 时，路径受到解析式屏幕空间偏转场影响，沿吸积盘切向弯曲；主像之外出现一条更暗、更短的次级弧，模拟强引力区的重复像。所有连接在光子环前逐渐增亮，进入事件视界遮罩后完全消失，绝不覆盖黑洞内部。

这一处理是视觉上的局部引力耦合，不声称替代 Boss 自身的物理光束追踪。它的作用是让“知识流被黑洞捕获”成为画面事件，而不是把 Boss 当作普通终点图标。

## 恒星层级

- 四颗恒星共享现有隐式体积材质：连续对流、细颗粒、暗磁区、色球层和不规则日冕。
- 四颗恒星保持同一材质家族，但尺寸、热度和活跃区分布略有差异，避免复制粘贴感。
- 汇合节点最大且最亮，入口节点次之，上下支节点略小；层级差控制在约 `1.25:1` 内，不能抢走 Boss 的第一焦点。
- Bloom 只扩散高温亮区，近景仍能看到表面细节。

## 动态与镜头

- 恒星表面、日冕、宽流带、细纤维和脉冲使用不同时间尺度，避免整个画面同步呼吸。
- 默认镜头固定为验收构图，只加入非常轻微的指针视差，不开放会破坏当前画面关系的自由飞行。
- 提供“整体”“连线近看”“黑洞汇入”三个视觉预设；默认整体视角必须同时读出局部知识区、连接拓扑和 Boss 压迫感。

## 验收标准

- 第一眼能分辨左侧是一个有面积的四节点知识区，而不是一条节点链。
- 连线看起来是空间中的流动场，不是管道、绳索、霓虹灯或粒子串。
- Boss 保持原有相对论黑洞画质，并始终是最大视觉中心。
- 终端连接在吸积盘附近明显弯曲、分像和被吞没，不穿过事件视界。
- 四颗普通节点仍然是有表面深度的活体恒星，不出现塑料球质感。
- 背景只服务于这个局部系统，不用铺满高亮星尘掩盖空虚感。

## 非目标

- 加入其余三到五个核心模块。
- 正式接入课程节点、连线交互、选中态或导航。
- 重做已经通过的 Boss 黑洞。
- 运行项目测试或修复无关业务问题。
