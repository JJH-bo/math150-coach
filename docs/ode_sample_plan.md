# ODE Sample Plan

ODE is the Phase 0 sample chapter because it has clear classification triggers, method families, transformations, and common false-pass patterns.

## Node Path

The sample graph covers:

- basic concept and order;
- general and particular solution;
- separable equations;
- homogeneous first-order equations;
- first-order linear equations and integrating factors;
- Bernoulli equations;
- reducible-order equations;
- second-order constant-coefficient linear equations;
- characteristic equations;
- nonhomogeneous particular solution form;
- Euler equations;
- application modeling.

## Design Intent

Each node includes:

- trigger patterns;
- scoring weights;
- rollback policy;
- pass criteria;
- variant policy placeholder.

This makes the sample graph useful for testing the engine rules without pretending to be a complete Mathematics I graph.
