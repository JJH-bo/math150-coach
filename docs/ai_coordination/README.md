# AI Coordination Workspace

This directory is the shared control area for the Math150 Coach "Twin Stars" workflow.

It is used by:

- User: final goal setter, decision maker, and real learner feedback source.
- ChatGPT: project brain, vision owner, architecture lead, implementation co-driver, GitHub writer, and review core.
- Codex: engineering execution lead, local runner, debugger, integration implementer, test runner, and code pusher.

## Purpose

This area is not a chat dump. It is the shared project memory and coordination layer for ChatGPT and Codex.

It should record:

- current project state;
- the single active task for Codex;
- ChatGPT's architecture and implementation guidance;
- Codex implementation reports;
- ChatGPT reviews;
- user decisions;
- phase freezes and handoffs.

## Files

- `CHATGPT_CORE_ROLE.md` — Twin Stars principle and ChatGPT's core responsibility.
- `PROTOCOL.md` — collaboration rules between User, ChatGPT, Codex, and GitHub.
- `WORK_HANDOFF.md` — structured work handoff area for active development tasks.
- `DISCUSSION_LOG.md` — concise communication log for important cross-agent exchanges.
- `DECISION_LOG.md` — user-approved decisions and project direction records.
- `CODEX_REPORT_TEMPLATE.md` — required format for Codex implementation reports.
- `CHATGPT_REVIEW_TEMPLATE.md` — required format for ChatGPT reviews.

## Operating Rule

GitHub is the shared fact source. ChatGPT and Codex should use this directory to reduce ambiguity, preserve project direction, and push Math150 Coach toward the highest final version, not just the safest MVP.
